# Pathfinder: Recursive Maze Solver

A Java-based desktop application that loads, validates, and solves text-based mazes using algorithmic recursion. 

## Features
* **Recursive Backtracking:** Implements Depth-First Search (DFS) to navigate the grid and backtrack from dead ends.
* **Custom Exception Handling:** Utilizes a custom `MazeException` class to enforce strict maze validation rules (e.g., dimension limits, start/exit verification, invalid character detection).
* **Automated Resource Management:** Built with Java's `try-with-resources` to ensure safe file I/O operations and prevent memory leaks.
* **Graphical User Interface (GUI):** Built with Java Swing to allow users to visually select files, view the original maze layout, and trace the generated solution path.

## Technologies Used
* **Language:** Java
* **Data Structures:** 2D Arrays, Linked Lists
